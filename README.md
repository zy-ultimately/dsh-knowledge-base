# 📚 知识库 — 让 AI 先读你的资料，再回答你

> 给 DeepSeek Harness 装一个专属资料库。把 PDF、Word、Excel、PPT 等文档放进去，
> 之后每次提问，AI 都会自动翻阅你的资料来回答，并告诉你答案出自哪份文档。

## ✨ 它帮你省下什么

**省时间。** 以前问 AI 专业问题，得先把文档内容一段段复制粘贴过去，又长又乱。
现在：文档放进去，直接问。AI 自动引用你资料里的内容作答，末尾还会标注
「来源：知识库《公司制度.pdf》」——答案有据可查，不用再自己翻文件核对。

**什么格式都能放。** PDF、Word、Excel、PPT、TXT、Markdown、CSV、网页文件，通通支持。

## 🚀 三步开始使用

1. **把插件装进 DSH**
   在 DSH 的插件设置里添加本插件（GitHub 仓库：`zy-ultimately/dsh-knowledge-base`），
   然后重启 DSH。重启后，左侧边栏会出现 📚 知识库入口。

2. **把你的文档放进去**
   点击 📚 → 上传文件 → 看到「已就绪」就是存好了。
   可以一次传多个，也可以随时删除或重新解析。

3. **直接提问**
   新建任意会话，像平常一样提问。AI 会自动查阅你的资料并回答，末尾注明来源。

## 💬 常见问题

- **我的文档会被传到网上吗？**
  不会。解析和检索全在你自己的电脑上完成，数据只存在本地。

- **扫描件 / 图片型 PDF 可以吗？**
  这类文件没有文字层，会提示「解析失败」。请改用文字版 PDF 再上传。

- **资料存在哪里？重启会丢吗？**
  存在你的工作区目录（默认 `.dsh-knowledge-base`），重启 DSH 后依然在。

- **不想让 AI 用我的资料？**
  在面板里关掉「自动检索」开关即可，随时可关。

## 🔒 说明

- 单文件最大 20MB。
- 插件可整体关闭，不影响 DSH 的聊天功能。
- 数据仅保存在本机，隐私无忧。
